# Brisbane Wedding Dresses

The current site export is in `public` and is ready for the GitHub preparation step.

- Entry point: `public/index.html`
- Supporting runtime: `public/support.js` and `public/image-slot.js`
- Embedded image state: `public/.image-slots.state.json`

The source ZIP used a `.dc.html` design-export format; the main document was renamed to `index.html` so it can be served by Cloudflare Pages.
